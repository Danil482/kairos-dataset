# Lab 1 - Ростислав Манзюк

Предсказываю, получил ли LinkedIn-пост меньше реакций, чем автор обычно получает,
примерно столько же или заметно больше. Основная метрика - macro-F1, дополнительно
считаю QWK, accuracy и матрицу ошибок.

Код сравнивает официальный baseline, CatBoost с расширенными признаками,
логистическую регрессию с TF-IDF и смешивание моделей. В CatBoost также добавлены
локальные эмбеддинги multilingual E5-small и признаки текстовой истории автора.

## Результаты и отчёт

Итоговый комплект находится в `submission/`:

- `Lab1_Rostislav_Manzyuk.pdf` - короткий отчёт с подходами и результатами;
- `selected_blend.csv` - один предсказанный класс на каждый из 17 623 test-постов;
- `metrics.json` - метрики, матрицы ошибок и доверительные интервалы;
- `selection.json` - параметры, выбранные на валидации до оценки test;
- `feature_importance.csv` - важности признаков CatBoost.

`Lab1.ipynb` содержит исполненный notebook. Настройки запуска зафиксированы в
`lab1_config.json`.

## Как воспроизвести

Нужен Python 3.9-3.12. Данные должны быть распакованы в `data/` или другую папку,
переданную через `--data`. Веса encoder скачиваются с Hugging Face, тексты
обрабатываются локально и во внешние API не отправляются.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-embeddings.txt
.venv/bin/python run_lab1.py --data data
```

Команда проверяет разметку, вычисляет эмбеддинги, обучает модели с уже выбранными
настройками, считает метрики, проверяет повторный inference и собирает PDF и CSV
для сдачи. Настройки по test повторно не подбираются. CUDA, Apple MPS и CPU
выбираются автоматически в таком порядке.

Для запуска notebook дополнительно нужны зависимости из
`requirements-notebook.txt` и ядро из этого окружения.

Отдельные команды:

```sh
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m kairos.label --data data
.venv/bin/python predict_lab1.py --data data
.venv/bin/python evaluate.py --data data --predictions results/lab1/selected_blend.csv
.venv/bin/python make_report.py
.venv/bin/python tools/prepare_submission.py --data data
```

Модель сохраняется в `results/lab1/model.joblib`. Веса, рабочие кеши и исходные
данные исключены из Git. Они восстанавливаются командами выше.

## Данные

Официальный источник - <https://kairos-labs.ai/dataset/>, baseline -
<https://github.com/Danil482/kairos-dataset>. Используется текущая версия релиза:
71 395 train-постов от 3 295 авторов и 17 623 test-поста от 824 авторов.

Для запуска нужны `authors/`, `posts/`, `labels.csv`, `split.json` и
`media/manifest.jsonl`. Сами картинки и видео не нужны. Текст документов и
метаданные вложений уже находятся в JSON постов.

Если места для всех томов core-архива не хватает, можно извлечь только нужные
файлы через HTTP Range. Пароль запрашивается интерактивно и не сохраняется:

```sh
.venv/bin/python tools/fetch_core_text.py --inspect
.venv/bin/python tools/fetch_core_text.py --output data --max-download-gb 1
```

Для этого релиза выборочное извлечение прочитало около 118 МБ и распаковало
около 787 МБ. CRC извлечённых файлов проверены. Проверка SHA-256 полных томов
не выполняется при таком способе загрузки; для неё нужны полные тома.
Архивы, пароль и исходные данные нельзя распространять вне курса.

## Проверка качества

Официальный test сохраняется без изменений. Внутри train отдельно выделены
659 авторов для валидации, seed 42. Все посты одного автора остаются в одной
части. Словари TF-IDF, заполнение пропусков, масштабирование, PCA и модели
обучаются только на обучающей части.

На валидации сравниваются глубина бустинга, размер эмбеддингов и смешивание
моделей. Результат выбора фиксируется в `selection.json`, после чего модели
переобучаются на всём train. Итоговый test используется для оценки, а не для
подбора параметров. Валидационные оценки после выбора могут быть оптимистичными.

95% доверительные интервалы считаются парным bootstrap по авторам,
2 000 повторов. Посты одного автора остаются вместе.

## Что входит в признаки

Время сбора в собственных признаках разбирается с `format="mixed"` в UTC.
Это восстанавливает 8 185 дат размеченных постов, потерянных исходным загрузчиком
из-за смешанной точности ISO-строк. Baseline использует исходную предобработку.

Признаки поста: длина и оформление текста, тип, время публикации, ссылки,
упоминания, метаданные картинок, видео и документов. Из профиля беру навыки,
описание, язык, страну, отрасль и характеристики карьеры.

История реакций сдвинута на один пост назад: средние, разброс, недавние изменения
и ритм публикаций. Текущие реакции, текущий residual, label и идентификаторы
автора и поста не входят в матрицу признаков. Текстовые коды людей и компаний
нормализуются, в том числе когда маркер обрезан на границе текста.

Encoder зафиксирован на ревизии
`614241f622f53c4eeff9890bdc4f31cfecc418b3`. Используется префикс `query: `,
длина ограничена 512 токенами. PCA обучается на train. Сходство текущего текста
с предыдущими постами считается по более ранним текстам, включая пять
начальных постов, у которых ещё нет метки.

Реакции и профили - снимки на момент сбора. Возраст поста на момент сбора и
текущее число подписчиков тоже используются, как в baseline. Поэтому результат
относится к этому офлайн-заданию и не доказывает такое же качество прогноза
сразу в момент публикации.

## Эксперименты

`train_lab1.py --validate-only` выполняет только валидацию, без оценки test.
`search_lab1.py` сравнивает глубины бустинга, используя уже посчитанные текстовые
вероятности на той же валидации. Повторное использование вероятностей проверяет
разделение, параметры и отпечаток входных признаков.

`embed_lab1.py --reuse-from <folder>` может повторно использовать неизменившиеся
каналы эмбеддингов. Для каждого канала проверяются encoder, ключи и хеш входных
текстов. Результаты на искусственных данных помечаются как fixtures и не могут
быть упакованы как официальная сдача.
